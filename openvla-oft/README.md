# AsyncMixVLA OFT runtime

This directory contains the inference-only OFT service, continuous observable trigger, asynchronous handoff, and Table 2 runner used by AsyncMixVLA. Use the repository-level [`README.md`](../README.md) for installation, artifacts, verification, and launch commands.

The upstream training and standalone experiment programs have been intentionally omitted from this deployment repository. The preserved `prismatic` files are the model components required to load and serve the OFT checkpoint.
